# AI Studio App

Welcome! This project contains everything you need to run the application on your local machine and continue development.

## Getting Started

Before you begin, make sure you have **Node.js** installed on your system.

### Installation

1. Install the project dependencies:

```bash
npm install
```

2. Create or update the `.env.local` file and add your  API key:

```env
GEMINI_API_KEY=your_api_key_here
```

3. Start the development server:

```bash
npm run dev
```

Once the server is running, open the URL shown in your terminal to view the application in your browser.

## Requirements

* Node.js
* A valid API key
* npm (comes bundled with Node.js)

If you run into any issues during setup, verify that Node.js is installed correctly and that your `GEMINI_API_KEY` has been added to the `.env.local` file.
